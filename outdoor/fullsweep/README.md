# Outdoor · Full TX×RX beam sweep

Exhaustive ground-truth capture for the outdoor testbed: at each measurement point the script sweeps every (TX beam × RX beam) pair and records SNR. Output is the raw per-pair SNR table that the online VIBE runners (in the parent folder) compare against.

This is the outdoor counterpart to the top-level `ground_truth_collection/` tree used by the indoor experiments.

## Files

| File | Role |
|---|---|
| `Sivers_BeamSweep_Delay_Optimized_SNR.py` | **Entrypoint.** Drives Sivers TX/RX through the full 64×64 beam codebook, captures USRP IQ per pair, computes SNR, and writes `snr_data.csv` + iteration timestamps + per-`tx_beam` IQ dumps. Two modes: `'F'` (full sweep, 64 TX × 64 RX) and single-TX mode (sweeps 64 RX for a chosen TX beam). |
| `Sivers_Plot_Tx_Rx_Heatmaps.py` | Imported by the sweep script as `heatmap`. `plotheatmap(sweep_directory_path, samples_per_beam)` reads `snr_data.csv` and renders a TX×RX SNR heatmap to disk. |

## Run

```bash
cd outdoor/fullsweep
python3 Sivers_BeamSweep_Delay_Optimized_SNR.py
```

The script connects to the TX server (raw TCP at `<TX_HOST_IP>:5002`), prompts for the sweep mode + TX beam choice, captures IQ for all (TX, RX) pairs, and writes the output tree.

## Output

A directory named after the experiment under your configured storage path (the script writes via the absolute `main_directory` defined in its `__main__` block — edit before running):

- `snr_data.csv` — `Sample size, Tx Beam, Rx Beam, SNR (dB)` per row.
- `iteration_timestamps.csv` — per-(tx, rx, iteration) start/end timestamps for latency analysis.
- `recv_signal/` — raw IQ vectors per (tx, rx, iteration), saved as `.bin`.
- `tx_beam_<idx>.dat` — final-iteration IQ buffer for each TX beam.
- `<exp_name>_heatmap.png` — generated by `Sivers_Plot_Tx_Rx_Heatmaps.plotheatmap`.

## Prerequisites

1. **Hardware up.** Sivers RX (local), USRP B200-mini, TX host running the raw-TCP TX server. See [../../docs/HARDWARE.md](../../docs/HARDWARE.md).
2. **TX server** at `<TX_HOST_IP>:5002` accepting `START_TX` handshake and `SET_TX_BEAM:<idx>` commands.
3. **Config edited.** In [../../configurations/config.py](../../configurations/config.py), set `PROJECT_ROOT`, `serial_port`, and the IQ parameters (`SAMPLE_SIZE`, `PADDING`).
4. **Storage path.** Edit `main_directory` near the bottom of `Sivers_BeamSweep_Delay_Optimized_SNR.py` to point at a writable volume — outputs are large (raw IQ per pair × per iteration).
